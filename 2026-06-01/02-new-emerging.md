**What's emerging:** xAI is signaling a **public-beta Grok 5 release in mid-June 2026** — coinciding with the IPO window ([`§1`](#1-xai-spacex-ipo)). Reported specs:

- **~6 trillion parameters** using a **Mixture-of-Experts** architecture (the "triple the parameter count" framing in coverage).
- **Native multimodal** — text, images, audio, video.
- **1.5 million token context window**.
- **Access**: **SuperGrok $30/mo** for the base subscription, **SuperGrok Heavy $300/mo** for priority access (in the same tier band as Claude Max-20x $200 and ChatGPT Pro).

## 3. OpenAI Codex CLI v0.134.0 — conversation search + per-server MCP env + OAuth for streamable HTTP {#3-codex-cli}

**What's emerging:** OpenAI shipped **Codex CLI v0.134.0 on May 26**, which is the **fourth Codex release in the April 23 → May 28 window** that's been quietly turning Codex CLI into a **persistent autonomous agent runtime** — the OpenAI side of the same "your terminal is the agent" architecture Claude Code pioneered.

What landed in v0.134.0:
- **Conversation history search** (`/history` retrieval — the kind of feature you don't realize you needed until you have a 50-conversation backlog).
- **`--profile` as the canonical model/runtime selector** (vs. multiple legacy flags).
- **Per-server MCP env targeting** (different env vars to different MCP servers — the multi-tenancy primitive).
- **OAuth for streamable HTTP MCP transports** — the auth primitive that lets you put MCP servers behind real auth gates without leaking secrets.

In the same April–May window, OpenAI also: promoted **GPT-5.5 Instant** to the **ChatGPT default** (**52.5% fewer hallucinations** on high-stakes prompts — [2026-05-10/01](../2026-05-10/01-big-lab-moves.md)), shipped **ChatGPT for Excel and Google Sheets**, made **Goal Mode default** in Codex, and **briefly leaked a GPT-5.6 rollout-map entry** before reverting to gpt-5.5 (canary, not a launch).
