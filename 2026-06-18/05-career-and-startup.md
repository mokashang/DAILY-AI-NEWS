## 4. The one weekend portfolio artifact: ship a public `SKILL.md` (60–90 minutes) {#4-skill-artifact}

The lowest-friction, highest-credential portfolio artifact you can ship right now is a single, well-designed Claude Skill, public on GitHub.

**Spec (60–90 minutes total):**

1. **Pick the workflow** — something you do every week: PR-review checklist, weekend planning, weekly billing audit ([`03` §3](./03-practical-skills-and-tools.md)), bug-triage triage, paper-summary template.
2. **Write `SKILL.md`** with proper YAML frontmatter (name, description, when-to-invoke triggers), 30–60 lines of body.
3. **Add `references/`** — 1–2 markdown files Claude can load on demand (e.g., a Markdown table of "how I write commit messages").
4. **Add `scripts/`** — at least one small executable (e.g., `audit_bill.py` placeholder).
5. **Write a tight `README.md`** — 1 paragraph on what the skill does, 1 paragraph on the architecture (progressive disclosure), 1 paragraph on how to use it.
6. **Public repo, MIT licence, clear name.** Pin it on your GitHub profile.

**Why this exact artifact:**

- **It's a real artifact**, not a tutorial walk-through. Recruiters at Anthropic / OpenAI Solutions / FDE roles open the SKILL.md file directly and read the YAML — a well-crafted frontmatter is a signature.
- **It scales with you** — every new role / interview / customer call you take, your skills folder grows. This is the **portfolio-version of dotfiles**, and it's the rarest portfolio asset on a CS-grad resume in 2026.
- **It's defensible** — a Skills repo is much harder to fake than "I built a chatbot."

### Why it matters to you

- **Job lens:** Pin the Skills repo above your generic SWE projects on your GitHub profile. In an interview, "I architect with Claude Code — here's my Skills repo" is a faster credibility signal than walking through any LeetCode-style code sample.
- **Startup lens:** A community-curated Skills marketplace is a **2026 wedge** (Y Combinator-shaped) — currently no one owns the equivalent of "npm for Skills." Whoever ships the registry + discovery layer first has a strong moat.
- **Insight:** The portfolio convention in CS-grad hiring is **always 18–24 months behind the actual job content**. Most resumes still show "ChatGPT wrapper" or "RAG chatbot." Recruiters at frontier labs are looking for **Skills, MCP servers, Hooks, cost-router code, eval harnesses, and verification-layer demos** — but most candidates don't know that yet. The thin queue is where the vocabulary is current.
