## 1. Ship the Colorado AI Act compliance memo tonight {#1-colorado-compliance}

**What:** A **1-page** (max ~600 word) memo titled **"Colorado AI Act compliance posture for a Claude-Code-built agent operating in a high-risk vertical."**

**Structure (target 90 minutes):**

1. **One-sentence scenario.** "Suppose you operate a Claude-Code-built agent that screens loan-officer follow-up tasks for a Colorado-licensed lender — Financial-Services = high-risk under the Act."
2. **The Act's three obligations (briefly):** *impact assessment, consumer notice + rights, AG-reportable incidents.* Cite the Colorado AG's effective-date guidance.
3. **Mapping each obligation to a concrete Claude-Code artifact:**
   - Impact assessment → a structured `IMPACT_ASSESSMENT.md` in the repo, generated by a one-shot Claude prompt + reviewed by a human (template included).
   - Consumer notice → an MCP server that surfaces the agent's reasoning summary on demand (this is the *output-provenance* concept from [2026-06-28/02 §2](../2026-06-28/02-new-emerging.md#2-abuse-detection-wedge) applied to *individual decisions*).
   - AG-reportable incidents → an automated webhook + log retention rule (yesterday's [trusted-channel proxy](../2026-06-28/03-practical-skills-and-tools.md#1-trusted-channel-proxy) is structurally similar).
4. **What this *does not* do:** explicitly disclaim — this is a *technical posture*, not legal advice. Cite the AG's authority + the lack of vendor-side safe-harbor.
5. **What an enterprise needs *in addition*:** a contracted attorney, a bias-evaluation harness (one paragraph; cite the methodology), and an explicit "human-in-the-loop on the consequential decision."

**Publishing path:**
- A new GitHub repo: `<your-handle>/colorado-ai-act-claude-compliance` with `README.md` (the memo) + a starter `IMPACT_ASSESSMENT.md` template + a minimal MCP-server stub.
- A LinkedIn / X post titled *"What I shipped the day before the Colorado AI Act went live."*

## 2. MCP at 10K servers — what changed and how to differentiate {#2-mcp-infra}

**State of the protocol (mid-2026):**

- **Scale:** **~10,000+ public MCP servers**; **97M+ monthly MCP SDK downloads**. ~1,864+ free servers listed on MCP.Directory.
- **Governance:** the protocol is now governed by **the Linux Foundation's Agentic AI Foundation (AAIF)** — a multi-vendor neutral home, not just Anthropic's spec anymore.
- **Security:** **OAuth 2.1** authorization with **incremental scope consent** added to the spec in **April 2026**. At **RSA Conference 2026**, **Cisco announced dedicated MCP security tooling** — the enterprise security industry now treats MCP as a first-class attack surface.
- **Leading servers to know:**
  - **Taskade** — workspace integration leader
  - **GitHub MCP** — code (now table-stakes for any coding agent)
  - **Exa** — search/research
  - **Brave Search MCP** — open-source web search alternative
  - **Fetch** — official Anthropic-shipped server for clean web-content pulling

**The differentiation bar (mid-2026):**

1. **5+ tools**, not 1.
2. **Real third-party API** integration (not a toy local file).
3. **OAuth 2.1 with scope consent** implemented correctly.
4. **5-case eval harness** showing edge cases — auth failure, rate limit, ambiguous tool selection, malformed input, network partition.
5. **README + a demo gif** (the demo gif drives 90% of recruiter clicks; ship it).

## 3. Agent SDK credit pool — two-week postmortem (still load-bearing) {#3-agent-sdk-cap}

**In effect since June 15:** Programmatic Claude (**Agent SDK, `claude -p`, GitHub Actions, OpenClaw**) bills against a **separate monthly Agent SDK credit pool** at **API list rates**:

| Plan | Monthly Agent SDK credit |
|---|---|
| Pro $20 | $20 |
| Max 5× $100 | $100 |
| Max 20× $200 | $200 |
| Team Standard | $20 / user |
| Team Premium | $100 / user |

**Two-week postmortem patterns that work** (most of these documented in the [Jun 14 official guide](https://www.marktechpost.com/2026/06/14/claude-code-guide-2026-25-features-with-examples-demo/)):

1. **Prompt caching first, always.** **60–90% input-cost reduction** on multi-turn workflows. Set `cache_control: { type: "ephemeral" }` on the static portions (system prompts, tool definitions, large reference docs).
2. **Opus-orchestrator + Sonnet-worker** routing — **~40% cheaper than all-Opus** with comparable end-quality on most measured tasks.
3. **Plan → annotate → "address all notes, don't implement yet" → approve → implement.** Cheap up-front planning calls catch the 80% of expensive failures before they consume the implementation budget.
4. **Primitive selection:** **slash command** = prompt template; **skill** = domain logic / helper files; **subagent** = isolated parallel work; **hook** = enforce a rule with code.
5. **Bedrock + OTEL** deepened — route through Bedrock with OpenTelemetry traces for per-tool-call cost attribution that finance teams accept.

Expect "how do you control the cost of an agentic workflow" to be a top-3 question in any AI-Integration / FDE interview after July 1. **Have specific numbers ready.**
