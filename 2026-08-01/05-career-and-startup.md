## 3. YC S26 runs mid-Aug application checkpoint {#3-yc-s26-checkpoint}

**Signal.** YC S26 ([YC](https://www.ycombinator.com/apply/)) is running July–Sept applications, interviews on rolling basis. Weekend of Aug-01 is the natural checkpoint to decide *whether* to submit — no clean interview slots open once mid-Aug hits.

**Decision framework — do this in 20 min tonight.**
- (a) Do you have a **wedge with a named anchor buyer**? (See [STARTUPS.md](../STARTUPS.md) wedge log.) If yes, apply. If no, don't.
- (b) Do you have a **demoable primitive** (2-min Loom, live URL)? If yes, apply. If no — spend this weekend building one, apply next round (W27).
- (c) Do you have a **cofounder**, or a very good reason to say "solo"? YC accepts solos but pattern-matches on 2-person teams. If solo, have a defensible answer.

If (a) + (b) + (c) are all yes: submit tonight, focus the video on the wedge (not the tech).

**Sources:** [YC official](https://www.ycombinator.com/apply/), yesterday's [YC S26 note](../2026-07-31/05-career-and-startup.md#5-yc-s26-summer).

**Why it matters to you.**
- **Job:** if you *don't* apply this batch, use the exercise anyway — the "wedge / primitive / cofounder" triad is also the framework for pitching a founding-engineer role at a Series-A vertical startup.
- **Startup:** YC S26 is a *forcing function*, not a *destination*. The 60-min application video is worth doing even if you don't submit — you can reuse it in the Ai4 cold DMs above.
- **Insight:** batch applications where you can name **one demoable primitive + one anchor buyer**  are the ones that convert. Everything else is a story about a future demo.
