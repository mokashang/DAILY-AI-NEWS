**Wedge 1: "ANT-adjacent intelligence tooling."** Build the dashboard a hedge-fund analyst or allocator would want in week 1 of ANT trading. Scrapes Anthropic blog + public docs + Ramp AI Index + public GitHub Code commit-share + public pricing + public customer logos. 2-week MVP; publish on the post-IPO Monday. Win the first-90-days attention window. Pivot to premium subscription if traction holds.

**Wedge 2: "Three-knob cost optimizer."** Bots that hook into your enterprise agent traffic and automatically re-tune (effort level, model choice, threads on/off) for cost-per-task. Priced at % of saved spend. Niche (requires Anthropic Enterprise contract exposure) but compounds with ANT adoption. Ship as an open-source primitive first + hosted version later.

**Wedge 3: "Content-provenance / watermark audit."** As detailed in [`03` §3](./03-practical-skills-and-tools.md#3-watermark-tooling). The 60–120-day pre-detector-API window is where to land the first customers (regulated-industry compliance teams; publishing orgs). Move before Anthropic ships its own detector.

**Wedge 4 (sector shift — robotics-up):** If you've been on the fence about robotics-adjacent work, the Nov-week funding tape (robotics $136M across 2 deals) is the signal. The 90-day startup entry is **robotics-eval-harness-as-a-service** — the robotics labs need Agentic Abstention + EnterpriseClawBench-style evaluation adapted to robot-task scenarios. Low capital, software-only, high willingness-to-pay from the robotics funders.
