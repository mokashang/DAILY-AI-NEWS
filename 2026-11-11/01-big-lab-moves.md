## 3. OpenAI terminates Cursor direct API access TOMORROW (Nov 12) following SpaceX / Anysphere acquisition {#3-openai-cursor-cut}

**What happened:**

- **Aug 14, 2026:** SpaceX closed its **$60B acquisition of Anysphere (Cursor's parent).**
- **Late August 2026:** OpenAI announced it would terminate Cursor's **direct, bundled API access to GPT models** 90 days later.
- **Nov 12, 2026 (tomorrow):** Cutoff date. Users retain access only via (a) their own OpenAI API key, (b) the Codex extension, or (c) third-party gateways. **Cursor loses contractual access to future OpenAI models (Astra, Sol, Luna, and whatever ships next).**
