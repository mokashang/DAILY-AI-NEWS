## Research Preprints
Where breakthroughs land before anywhere else.

- [arXiv cs.AI](https://arxiv.org/list/cs.AI/recent) — AI papers daily
- [arXiv cs.LG](https://arxiv.org/list/cs.LG/recent) — ML papers daily
- [arXiv cs.CL](https://arxiv.org/list/cs.CL/recent) — NLP / LLM papers
- [Hugging Face Papers (Trending)](https://huggingface.co/papers/trending) — curated hot papers
- [alphaXiv](https://www.alphaxiv.org/) — arXiv with community discussion
- [Semantic Scholar](https://www.semanticscholar.org/) — search and citation graphs
- [Papers With Code](https://paperswithcode.com/) — papers + benchmarks + code
