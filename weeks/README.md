# weeks/ — Sunday Rollups

Each `WEEK-YYYY-MM-DD.md` file is a single-page rollup of the week starting on the named Monday.

Purpose: **compress 5–7 daily editions into the 5 stories that mattered** for the goals in [`../ME.md`](../ME.md), so you can re-read a whole month in ~20 minutes.

## Format

```
# WEEK-YYYY-MM-DD (Mon → Sun)

## The 5 stories that mattered for me this week
1. ...
2. ...
3. ...
4. ...
5. ...

## What I shipped
- artifact 1 (link)
- artifact 2 (link)

## What I dropped (and why)
- ...

## Trackers delta
- ACTIONS.md: X closed / Y opened
- APPLICATIONS.md: N applied / M replies / K interviews
- STARTUPS.md: wedges promoted/demoted
- WATCHLIST.md: threads closed/added

## Next week's focus
One sentence.
```

## Cadence

Written Sunday evening, after the Saturday daily edition. Adds the previous Monday→Sunday block. Promised in [ACTIONS.md](../ACTIONS.md) for 2026-05-24; convention starts this week (2026-06-08 → 2026-06-14 → file `WEEK-2026-06-08.md`).

## Why this file exists

The daily editions are dense. Without a weekly compression layer, the archive becomes write-only.
